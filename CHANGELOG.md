# История изменений

Изменения, подтверждённые по версиям проекта. Архивы предыдущих версий не нужны для текущей установки.

## 2.3.2 — 16 октября 2026

- Прокрутка только внутри панели «Поиск и настройка подключения по Wi-Fi», без прокрутки всего окна.
- Крупная кнопка «Начать трансляцию», зелёная лишь после успешной проверки ADB для текущих IP и порта.
- Изменение IP или порта сбрасывает подтверждённую готовность до новой проверки.

## 2.3.1 — 16 октября 2026

- Поиск уже доступного устройства через ADB и настройка подключения по Wi-Fi через USB объединены в одну панель.
- Пояснения для каждого сценария и раскрывающаяся инструкция по первому подключению.

## 2.3.0 — 16 октября 2026

- Автопоиск доступных по ADB TCP/IP-устройств при запуске; сохранён ручной поиск.
- Подбор устройства при нескольких найденных подключениях.
- Настройка ADB TCP/IP по USB через GUI и встроенные инструкции.
- Автопоиск работает только с уже известными ADB подключениями; сканирование локальной сети не выполняется.

## 2.2.2 — 16 октября 2026

- Версия в интерфейсе считывается из `Info.plist` вместо жёстко заданного значения.

## 2.2.1 — 16 октября 2026

- Исправлено имя архива scrcpy для Apple Silicon: `aarch64` вместо `arm64` в URL загрузки.

## 2.2.0 — 16 октября 2026

- Автоматическая загрузка отсутствующих scrcpy 5.0.1 и ADB в каталог приложения.
- Проверка SHA-256 архива scrcpy и работоспособности встроенных утилит.
- Установка через временную сборку с сохранением предыдущей версии при ошибке.

## 2.1.0 — 16 октября 2026

- Переименование Huawei Screen в Android Screen.
- Графические настройки IP, порта и пути к исполняемому файлу scrcpy.
- Нативный SwiftUI-интерфейс и новая иконка.
