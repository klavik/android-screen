Android Screen 2.3.2 — macOS 12+ (Apple Silicon и Intel)
========================================================

Графическая оболочка для scrcpy: трансляция экрана Android на Mac по Wi-Fi.
Проект scrcpy: https://github.com/Genymobile/scrcpy
Android Screen — независимая оболочка, неофициальный проект.

УСТАНОВКА
1. Распакуйте архив целиком.
2. Запустите «Установить Android Screen.command» двойным кликом.
3. Установщик проверит Swift/macOS SDK и встроенные scrcpy/ADB.
4. Отсутствующие scrcpy и ADB он загрузит из официальных источников
   непосредственно в Android Screen.app. Для ADB нужно принять условия Google.
5. Откройте ~/Applications/Android Screen.app, укажите IP и порт Android.

Homebrew и Android Studio не нужны.
Apple Command Line Tools устанавливаются в macOS, а НЕ внутрь приложения.
Если их нет, установщик запросит системную установку. После её завершения
нужно запустить установщик ещё раз.

Инструменты будут находиться в:
~/Applications/Android Screen.app/Contents/Resources/Tools/

scrcpy: https://github.com/Genymobile/scrcpy/releases/tag/v5.0.1
ADB: https://developer.android.com/tools/releases/platform-tools
Swift / macOS SDK: https://developer.apple.com/download/all/

После установки полный README.md содержит инструкции по включению отладки,
подключению по USB / Wi-Fi, настройкам GUI и устранению ошибок.

При обновлении предыдущее приложение сохраняется в резервной копии.

НОВОЕ В 2.3.0
- При запуске выполняется поиск доступных Wi-Fi-устройств через ADB.
- Ручная кнопка поиска осталась; при нескольких устройствах можно выбрать нужное.
- В едином блоке GUI есть поиск через ADB и кнопка «Настроить подключение по Wi-Fi через USB».
- Автопоиск видит уже подключённые ADB-устройства, а не сканирует сеть.

НОВОЕ В 2.3.1
- Поиск через ADB и настройка через USB объединены в один блок с пояснениями.
- Инструкция первого подключения раскрывается внутри блока.

НОВОЕ В 2.3.2
- Только встроенная прокрутка в панели поиска и настройки; внешняя прокрутка окна убрана.
- Крупная кнопка трансляции зелёная только после успешной проверки ADB с текущими IP и портом.
