# Android Screen 2.3.2 — GitHub Release

Android Screen — бесплатная графическая оболочка для macOS, позволяющая транслировать экран Android и управлять устройством через Wi-Fi.

### Возможности

- Подключение Android по Wi-Fi через ADB с настройкой IP и порта.
- Автоматический и ручной поиск доступных ADB-устройств.
- Настройка ADB по Wi-Fi через USB из интерфейса.
- Встроенные scrcpy и ADB загружаются установщиком.
- macOS 12+, Apple Silicon и Intel.

### Установка

Скачайте установочный ZIP из Assets, распакуйте и запустите `Установить Android Screen.command`. Для сборки приложения понадобятся Apple Command Line Tools; отдельная установка Homebrew не требуется.

### Используемый проект scrcpy

Android Screen — неофициальная независимая оболочка на базе **[scrcpy](https://github.com/Genymobile/scrcpy)**. Благодарим авторов и участников проекта scrcpy за инструмент трансляции и управления Android. Android Screen не является официальной частью scrcpy.

Исходный код и документация scrcpy: https://github.com/Genymobile/scrcpy
