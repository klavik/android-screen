# Разработка и выпуск

## Структура

- `Исходники/AndroidScreen.swift` — приложение SwiftUI и логика запуска scrcpy/ADB.
- `Исходники/AndroidScreen.iconset/` — исходники иконки для `iconutil`.
- `Исходники/AndroidScreen.svg` / `.png` — дополнительные форматы иконки.
- `Установить Android Screen.command` — сборка, загрузка/проверка официальных scrcpy и ADB и установка в `~/Applications/Android Screen.app`.
- `README.md` — установка и эксплуатация.

## Проверки перед релизом

На Mac с macOS 12+ и установленными Apple Command Line Tools:

```bash
bash -n 'Установить Android Screen.command'
./'Установить Android Screen.command'
```

Убедитесь, что SwiftUI компилируется, приложение запускается, параметры IP/порта сохраняются, ADB подключается по Wi-Fi, scrcpy начинает и прекращает трансляцию. Проверьте также повторный запуск установщика, перенос встроенных утилит и создание резервной копии.

Приложение собирается во временном каталоге и заменяет установленную копию только после проверки утилит. Скрипт не модифицирует системные установки Homebrew.

## Повышение версии

Номер версии сейчас используется в нескольких местах **установочного скрипта**: заголовок, комментарий, `CFBundleShortVersionString`, `CFBundleVersion`, сообщение об успешной установке. Перед выпуском синхронно обновите эти значения, `README.md`, `README.txt` и `CHANGELOG.md`.

Готовые `.app` и архивы релизов не фиксируются в Git: прикладывайте ZIP исходников и установщика к GitHub Release. В репозитории не должно быть личных настроек, логов, ADB-ключей или закрытых бинарников сторонних приложений.
